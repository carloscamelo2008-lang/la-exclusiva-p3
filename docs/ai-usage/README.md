# Bitácoras de uso de IA

Cada integrante debe mantener una bitácora propia desde su primera interacción real con una herramienta de inteligencia artificial en este proyecto.

## Archivos

- leader-ai-log.md: Carlos Eduardo Camelo Montaño.
- developer1-ai-log.md: Jesús Daniel Díaz Álvarez.
- developer2-ai-log.md: Daniel Josué Arrieta Fontalvo.

## Qué registrar

Para cada interacción relevante, anotar:

1. Fecha.
2. Herramienta utilizada.
3. Fase, tarea y rama de Git relacionada.
4. Objetivo de la consulta.
5. Resumen de la sugerencia recibida.
6. Qué revisó, aceptó, modificó o descartó el integrante.
7. Evidencia de verificación, como una prueba, diff o revisión del documento.

## Reglas

- Cada integrante registra únicamente sus propias interacciones reales.
- No copiar una bitácora ajena ni inventar consultas o actividades.
- Si una interacción antigua se recuerda después, señalar la fecha real si se conoce y dejar claro que el registro es retrospectivo.
- La IA puede sugerir código o documentación, pero cada integrante debe comprender, revisar y probar los cambios antes de integrarlos.
- Las bitácoras no deben contener contraseñas, datos privados ni información personal real de los clientes.
