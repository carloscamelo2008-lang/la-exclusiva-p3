# Mockups visuales de la interfaz final

**Estado:** pendiente de elaboración visual.

Este archivo reserva el espacio documental para los mockups o wireframes solicitados en la fase 2. Los diseños se crearán como imágenes o wireframes visuales en una tarea posterior; este documento no representa una entrega visual terminada.

## Pantallas que se diseñarán

1. Panel de operación diaria.
2. Registro de venta con varias referencias, presentación, pago inicial y saldo.
3. Catálogo e inventario por canastas completas y unidades sueltas.
4. Consulta de clientes, fiados, abonos e historial de saldos.
5. Registro de pedidos de mercancía y recepción parcial.
6. Registro y consulta de ingresos y egresos.

## Criterios visuales

- Textos y mensajes en español.
- Valores monetarios en COP.
- Mostrar la equivalencia de unidades al seleccionar media canasta.
- Diferenciar total de venta, valor pagado y saldo pendiente.
- Separar media canasta comercial de una cava física prestada.
- Usar datos ficticios en las imágenes.

La primera entrega utiliza consola. La interfaz gráfica JavaFX se desarrollará posteriormente y reutilizará los servicios del sistema.
